# projectG

Rustikalni prototip sajta za izložbu i udruženje.

## Pokretanje lokalno

Otvori `index.html` u pregledaču ili preko VS Code Live Server ekstenzije.

## GitHub Pages

1. Pošalji promene na `main` granu.
2. U GitHub repozitorijumu otvori Settings > Pages.
3. Kao source izaberi `Deploy from a branch`.
4. Kao branch izaberi `main` i folder `/ (root)`.

Stranica je već spremna za Pages jer koristi samo statičke fajlove: `index.html`, `styles.css` i `script.js`.
